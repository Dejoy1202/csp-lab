## 界面与构建

题面左侧独立滚动、右侧持续显示 Monaco，顶部五题切换和倒计时。采用系统无衬线字体、16px 正文、1.85 行高和 15/16/18/20 字号选择；数学使用本地 KaTeX 字体，C++ 代码保留原样。浅色与炭灰深色可切换，作答区没有粒子或装饰动画。

实测桌面 1440×900 和手机 390×844；手机题面与编辑器上下排列，页面内容宽度等于视口，无整页横向溢出。最终截图位于 docs/validation/mock-ui/。对深色裸按钮、主按钮和小字状态颜色的对比度问题已修复。

TypeScript 与 Vite 生产构建通过。初始主包约268KB（gzip85KB）；编辑器只在进入作答时加载。作答块包含本地 Monaco/C++ 组件，约3.08MB（gzip812KB），Vite仍提示大块。npm run lint 退出码0，16条提示，主要为 React effect 依赖和已有组件模式；不能称为零告警。

## 复现

先启动 Docker 服务并导入已验证题包，在 frontend 中执行：

```powershell
npm ci
npm run build
npm run test:e2e
```

默认使用本机 Edge，也可指定 CSP_BROWSER_PATH。完整测试会注册随机 qa_ 账号，测试数据带明确前缀，不结束管理员已有考试。测试脚本读取 .env 的受信任工具密钥；网页只用 HttpOnly Cookie 和 CSRF，不接收 API_KEY。trace关闭，密码不写入报告。

容器重启后的逐表数据校验、再次登录和成绩检查见 [核心测试说明](TESTING.md) 与 validation/mock-redesign-persistence.json。旧 frontend-summary.json / frontend-persistence.json 为之前版本的历史记录，不能代表当前产品范围。
