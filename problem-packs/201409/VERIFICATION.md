# 201409 数据与参考验证

每题20个本站独立测试点，每点5分。固定种子2014091401；每题40次独立小数据对拍，另核对本站原创样例。没有使用官方或第三方隐藏数据。

|题目|确定性特殊情况和规模|独立答案模型|
|---|---|---|
|相邻数对|单个元素、0/1、9999/10000、逆序、连续/不连续、n=1000|逐对枚举，与排序扫描区分|
|画图|坐标0/100、重叠/重复100次、接边、零面积、100个矩形|横向条带扫描合并纵向区间，与单位格涂色区分|
|字符串匹配|大小写标志、前/后缀、无匹配、重复行、保留原始大小写、100字符×100行|逐字符窗口比较，与字符串find区分|
|最优配餐|重复客户、多个等距离门店、绕行、店即客户、999999个障碍/门店、1000000客户、费用1998000000000|n≤100逐客户反向BFS；大规模用已证明形状的解析路径|
|拼图|面积非3倍、单行/单列、四朝向、奇偶高度、m=7、n接近10^15|小板精确覆盖枚举；大板转移序列的线性递推，与参考矩阵幂区分|

大规模配送的解析数据族：客户全部在门店则距离0；单门店(1,1)且仅障碍(2,2)时沿边界的单调路径可达，距离x+y−2；第二列前n−1行被阻塞时，右侧客户必须经底部缺口，距离2n−x+y−2。输入校验器逐条检查范围、数量、障碍唯一性与客户可达性；不把不可达点塞进合法数据。

拼图枚举2×2区域去掉一格得到四个L型朝向。先计算转移序列，由模素数域上的Berlekamp–Massey恢复递推，并在未参与拟合的后续项检验；小尺寸再与不使用行转移的整板精确覆盖比较。参考程序通过可达状态矩阵快速幂计算，最大高度使用64位整数。

mutations.json列出10个可编译的故意错误程序变换。mutations.py必须找到正式点上的失败见证，才算覆盖这类错误。已实际检测全部10种，包括漏0、无排序、重叠重复计数、端点面积错误、大小写和原文输出错误、32位费用、重复客户覆盖、32位高度及缺失骨牌朝向。此检查不声称穷尽所有错误。

复现：docker compose run --rm pack-builder python early.py --batch 201409 --import。真实账号模考验收：python verify_exam.py --batches 201409。正式提交仍每个测试点建立独立Docker沙箱；validation_runtime仅为仓库自写参考/错解的离线数据建设复用容器，每个输入启动新受限进程。
