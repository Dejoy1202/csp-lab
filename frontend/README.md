# CSP Lab 前端交付说明

CCF-CSP 300+ 专属算法训练与全真模拟判题平台前端，使用 React 19 + TypeScript + Vite 构建，集成 Monaco Editor C++17 编辑器。页面由外部 AI 提供；本轮修复接口与训练流程，保持原有 CSS 和页面布局。功能验收见 ../docs/FRONTEND_TESTING.md。

---

## 启动与运行

在项目 `frontend/` 目录下：

```bash
# 安装依赖（若首次运行）
npm install

# 启动开发服务器（端口 5173）
npm run dev

# 生产环境编译检查
npm run build
```

开发服务默认运行于 `http://localhost:5173`。已通过 `vite.config.ts` 反向代理 `/api` 到 `http://127.0.0.1:8080`，避免浏览器跨域拦截。

## 已实现的页面与功能清单

### 1. 连接入口 (`/login`)
- **本地单用户密钥连接**：对接单用户本地后端，通过用户输入的 `X-API-Key` 发送 `/api/dashboard` 请求测试连通性。
- 密钥保存在客户端 `localStorage`，不写入任何 Git 源码。
- 提供“断开连接”按钮，一键清空本地密钥缓存并退出到连接页。
- 采用磨砂玻璃拟物设计，背景配置轻量 Canvas 粒子动效。

### 2. 训练首页 (`/`)
- **顶栏 Hero 科技感展板**：
  - “目标 300+” 鲜明徽章，“继续训练”与“202403 模拟考试”首屏快速启动入口。
  - Canvas 2D 粒子微动效（低透明度青蓝粒子，稀疏慢速，支持后台标签页自动暂停、`prefers-reduced-motion` 动效偏好及随时一键开关）。
  - 总题数、攻克数、AC 通过率、连续训练天数四大核心指标。
- **300+ 目标进展看板**：直观展示距离 300 分冲刺基准线的完成百分比。
- **Recharts 轻量图表可视化**：
  - 近期每日提交趋势折线图（DailyTrend）。
  - 算法标签掌握度分布进度条（TagProgress）。
  - 未通过错误类型分布柱状图（ErrorTypeDistribution，WA / TLE / RE / CE 等分类着色）。
- **动态汇总**：最近提交记录快照、最近模拟考试成绩单（统一标注“本站模拟评分”）。

### 3. 题库中心 (`/problems`)
- 多维度综合筛选：批次（202403真题 / 原创专项）、难度（基础/中等/困难）、完成状态（未提交/已尝试/已通过）、算法标签完整名称筛选。
- 完备的元数据展示：题目编号、名称、标签徽章、时空限制、评测机制（本站完整数据评测 / 仅样例测试 / 外部来源链接）。
- 严格的状态控制：“建设中（BUILDING）”题目带有明确警示标签，限制正式提交。
- “整套试卷”切卡：读取 `/api/papers`，展示已收录批次就绪状态及 5 题直通。

### 4. 刷题工作区 (`/problems/:id`) —— 核心模块
- **双向无级拖拽分栏**：
  - 左右分栏：题面阅读与代码编辑区无级拖拽调整比例（25%~75% 范围限制）。
  - 上下分栏：编辑器与测评结果面板高度无级调整。
  - **专注模式**：一键折叠题面左栏，代码编辑器全宽展开。
- **安全题面渲染**：
  - 使用 `marked` + `DOMPurify` 深度过滤危险 HTML。
  - 规范渲染输入/输出格式、数据规模与约定、子任务捆绑分值说明。
  - 样例卡片支持**一键复制输入**与**一键复制输出**。
- **Monaco Editor (C++17)**：
  - 适配深浅双色主题（vs / vs-dark）。
  - 字号灵活微调（A- / A+）。
  - **防冲突草稿机制**：1.5秒防抖自动保存，串行发送更新并使用标签页临时备份，携带 `revision` 版本号；若捕获 409 冲突，弹出确认对话框保留本地代码或加载最新服务端版本。
  - 快捷键支持：`Ctrl+S` / `Cmd+S` 随时立即保存。
- **评测与结果呈现**：
  - “▶ 运行样例”与“🚀 提交判题”独立流转，防止重复点击。
  - `usePolling` 自动化轮询：`QUEUED` / `RUNNING` 状态呼吸动效提示，到达终态即刻停止轮询，卸载组件安全回收。
  - 样例运行显著标注“样例运行（不计分）”，展示截断的安全 stdout 输出。
  - 正式判题测试点列表展示：分值、执行毫秒、内存 KB、负 exitCode 信号翻译（如 `-11` 标为 `SIGSEGV`）。
  - 编译错误（CE）：单独展示完整编译诊断并支持一键复制。
  - “提交记录”侧栏标签：可点击查看本题历史提交并“一键恢复历史代码”。

### 5. CSP 模拟考试 (`/exam` & `/exam/:id`)
- **202403 第33次真题的 4 小时 5 题本站模拟**：
  - 从 `/api/papers/202403` 动态装载按真实顺位排序的 5 道题目。
  - 客户端倒计时：基于服务端 `remainingSeconds` 与 `performance.now()`，每2秒同步服务端状态；截止时间与提交许可由后端控制。
  - 倒计时预警：剩余时间小于 30 分钟与 5 分钟呈现阶梯警示颜色。
- **多题并行答题面板**：
  - 顶部 T1~T5 切换卡，实时展示每题累计最高分（无罚分）。
  - 每道题内嵌完整编辑提交环境，提交自动绑定 `examId`。
- **交卷与复盘流程**：
  - 交卷前进行二次确认提示。
  - 若有后台待判任务，界面明确提示等待后台队列结算。
  - 考试结束后生成结构化总成绩单与每题得分明细（标注“本站模拟评分，非官方认证成绩”）。
  - 支持逐题与单次提交历史代码复盘。

### 6. 错题复盘本 (`/notes`)
- 自动汇聚所有非 AC 的错题，支持“全部 / 待攻克 / 已掌握”筛选。
- 卡片展示历史未通过次数、当前题目版本最高分和笔记更新时间；全局错误类型统计在首页查看。
- **在线反思与笔记编辑**：
  - 思路陷阱与心得文本编辑。
  - 自定义错因标签输入与管理（如 `#开longlong`、`#前向星建图`）。
  - 掌握状态勾选切换。
  - “🚀 去重刷”一键直达对应题目工作区。

### 7. 提交记录查询 (`/submissions`)
- 支持按评测终态（AC/WA/TLE/MLE/RE/CE/SYSTEM_ERROR）、题目 ID、模考 ID 进行精准筛选与翻页。
- 点击任意提交行即可展开完整的评测报告模态框，包含测试点耗时、内存、状态、编译报错以及只读 Monaco 源代码查看与代码恢复。

### 8. 题目管理中心 (`/admin`)
- **题包资产导入**：
  - 单题 JSON 文件上传（`POST /admin/problems/import`）。
  - `.json.gz` 完整压缩题包上传（`POST /admin/problems/import-pack`，解压入库不调取外网）。
- **单题可视化录入**：
  - 手动创建只支持建设中题目或仅样例测试题，必须填写实际使用许可与评分说明。正式测试点、评分配置与验证报告通过 JSON 题包导入，样例不会充当正式测试数据。
- **批量 JSON 原创题包录入**：
  - 支持最大 20 题原子事务创建，提供错误回滚提示。

## 视觉与交互规范落地

1. **色彩与材质**：
   - 石墨灰（`#1a1a2e`）、雾白（`#f8f9fa`）、柔和边框（`#e2e4e8` / `#3a3a55`）。
   - 低饱和青蓝品牌强调色（`#3a7ca5` / `#5ba8d5`）。
   - 绿色（`#2d8a56`）表示通过，红色（`#c44040`）表示错误，橙色表示超时/内存超限，紫色表示编译诊断。
   - 提供**日间 / 夜间**完整双主题，支持全局字体调节与 Monaco 字体调节。
2. **Jakob Nielsen 可用性设计**：
   - **状态可见**：保存中、已保存、排队中、判题中均有动态徽章与提示。
   - **防错设计**：交卷与覆盖现有草稿需明确弹窗确认；按钮在请求及判题中禁用；查询失败只重试 GET，不自动重复提交。
   - **无干扰设计**：草稿自动保存静默更新状态文字，不弹出突兀弹窗；所有弹窗关闭后不争夺 Monaco 编辑器焦点。

## 浏览器集成验收

```powershell
npm ci

```

Windows 默认使用已安装的 Edge，无须重复下载浏览器。WSL 可使用已安装的 Chromium，通过 CSP_BROWSER_PATH 指定其路径；也可按 Playwright 的官方安装方式配置浏览器。测试连接真实 Spring Boot / MySQL / Docker Worker，不模拟判题结果。会创建 UI- 前缀的专用题目、提交、笔记及模考记录。

结果在 ../test-results/playwright/report/index.html；截图与报告不得上传含本机访问密钥的内容。自动测试关闭 trace，密钥从 ../.env 读取，不写入源码。
